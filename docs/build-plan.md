# Solar System Simulator — Build Plan

## Step 1 — Create window
Initialize pygame and create a blank window.

## Step 2 — Draw one planet
Render a circle at a fixed position.

## Step 3 — Add movement
Give the planet velocity and update its position each frame.

## Step 4 — Add second planet
Make both planets move independently.

## Step 5 — Add gravity
Use Newton's law to pull planets toward each other.

## Step 6 — Add the Sun
Make it massive so planets orbit it.

## Step 7 — Add trails
Store previous positions and draw lines.

## Step 8 — Add scaling
Scale distances so planets fit on screen.

## Step 9 — Add time warp
Allow speeding up or slowing down the simulation.

## Step 10 — Add moons
Moons orbit planets the same way planets orbit the sun.
